One word for the 'One Word for Your Wi-Fi' bounty: **Ghosting** — home Wi-Fi vanishes right when you need it most, mid-call or mid-download, without a word of explanation. Funny because it is true, instantly understood, and it works perfectly as a Wi-Fi network name. The program writes that single word to /output/entry.txt.

## Run it

```sh
python3 main.py
```
